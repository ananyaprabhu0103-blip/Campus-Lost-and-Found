# Campus Lost and Found

## Project Description

Campus Lost and Found is a simple frontend web application developed using HTML, CSS, and JavaScript. It allows users to enter details of lost or found items, display them on a webpage, and search through the reported items.

## Objectives

* To create a webpage for entering lost and found item details.
* To display submitted items in separate sections.
* To implement a search feature using JavaScript.

## Technologies Used

* HTML
* CSS
* JavaScript
* Visual Studio Code

## Features

* Enter item name, description, status, and location.
* Submit lost or found item details.
* Display submitted items as cards.
* Search for items using the search box.
* Separate sections for lost and found items.

## Project Structure

```text
Campus-Lost-and-Found/
│
├── index.html

├── script.js
└── README.md
```

## Working

The HTML file creates the structure of the webpage, CSS is used for styling, and JavaScript adds functionality. When a user submits an item, JavaScript reads the entered details, creates an item card, and displays it in the appropriate Lost or Found section. The search feature filters the displayed items based on the entered text.

## Limitations

* Item details are not permanently stored.
* Submitted items disappear when the webpage is refreshed.
* The project does not include a backend or database.
